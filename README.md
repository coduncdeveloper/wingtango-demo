# WingTango — prototype demo

A **compiled prototype** of WingTango, a modern aircraft marketplace with co-ownership partner matching. This repository contains only the built static site, published so it can be viewed in a browser.

**Live demo:** https://norbok7.github.io/wingtango-demo/

## What this is and is not

- **Prototype, not a live product.** All listings, partner profiles, messages, and metrics are demonstration data. There is no real inventory and nothing is for sale.
- **No backend and no accounts.** Everything runs in your browser and persists to local storage. Sign-in is a persona picker with no passwords. Nothing you do here is sent anywhere.
- **Aircraft photographs are representative images of each type,** not photographs of specific airframes. All 38 are public domain or Creative Commons licensed from Wikimedia Commons, with author and licence credited on the in-app **Photo credits** page.

## Try it

Click **Demo access** to switch perspective, or deep-link with `?as=`:

| Persona | Link |
|---|---|
| Buyer, partnership-seeking | `?as=usr-milo` |
| Broker with 20 listings | `?as=usr-dana` |
| Platform admin | `?as=usr-admin` |

The one screen worth seeing first is **Partner map** — map-based co-ownership discovery, the product's differentiating feature.

Use **Reset demo data** (footer of the admin screen, or the persona picker) to restore the seeded state.
